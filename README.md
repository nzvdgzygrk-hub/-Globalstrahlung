# Globalstrahlung – 7 Tage

Kleine PWA für die 7-Tage-Prognose der Globalstrahlung (GHI) in W/m².

- automatische Standortabfrage
- 7 Tage Vorschau
- stündliche Werte
- Tagesmaximum und Tagesenergie in kWh/m²
- einfache PV-Richtwertbewertung
- iPhone Home-Screen-Icon

Datenquelle: Open-Meteo Forecast API (`shortwave_radiation`).

Bereitstellung: GitHub Pages aus `main` / `root`.
